# Karthik Balaji Portfolio

A lightweight portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or serve the project with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Update the content in `index.html` to add your own:
- name and introduction
- project details
- contact links
- skills and experience

## Files

- `index.html` — page structure and content
- `styles.css` — styling and responsive layout
- `script.js` — mobile navigation behavior and footer year
